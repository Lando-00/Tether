# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues:
`Lando-00/Tether`.

## Conventions

- Use the authenticated `gh` CLI for issue and pull-request operations.
- Create issues with `gh issue create`.
- Read issues with `gh issue view <number> --comments`.
- List work with `gh issue list`, applying the configured labels and state
  filters.
- Apply or remove labels with `gh issue edit`.
- Keep pull requests out of the normal triage request surface unless explicitly
  requested; this repository's setting is `no`.

When a skill says to publish a specification or ticket, create a GitHub issue.
When it says to fetch a ticket, read the complete issue body and comments.
